# Il Tesoro del Drago · The Dragon's Hoard

Gioco incrementale per browser e telefono: un drago vuole riempire la sua grotta con tutto l'oro del mondo.
An incremental browser and phone game: a dragon wants to fill its cave with all the gold in the world.

**Gioca / Play:** https://druminalgodev.github.io/dragon-cave/

Su Android apri il link in Chrome e scegli "Aggiungi a schermata Home" per installarlo come app (funziona anche offline).
On Android, open the link in Chrome and choose "Add to Home screen" to install it as an app (it also works offline).

## File

- `index.html`: tutto il gioco (HTML, CSS e JavaScript, nessuna build).
- `manifest.webmanifest`, `sw.js`, `icon-*.png`: installazione come app e gioco offline.
